# 🧘 Yoga Pose Detection

A computer vision project that detects and identifies yoga poses from images or video using deep learning and pose detection techniques.

## 📌 Project Overview

**Yoga Pose Detection** is designed to recognize yoga poses from visual input and provide the detected pose as the output.

The project uses computer vision and machine learning techniques to process the input and identify different yoga poses. It can be useful for yoga practice, posture monitoring, fitness applications, and beginner-level pose guidance.

## ✨ Features

* 🧘 Detects yoga poses from visual input
* 📷 Supports image-based pose detection
* 🎥 Can be used with video/webcam input
* 🤖 Uses computer vision and deep learning techniques
* 📊 Provides pose detection results
* 💻 Simple and easy-to-use application structure

## ⚙️ How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/Pavani-2116/Yoga_Pose_Detection.git
```

### 2. Open the Project Folder

```bash
cd Yoga_Pose_Detection
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install Required Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Then open the local URL displayed in the terminal, usually:

```text
http://127.0.0.1:5000/
```
